磁铁与磁场小测

共 10 题 · 含答案与解析

  1. 1. 把 N 极与 S 极靠近，会发生什么？

    1. A排斥
    2. B吸引
    3. C先吸引后排斥
    4. D没有相互作用
    答案：吸引
    解析：同名磁极相互排斥，异名磁极相互吸引；N 极与 S 极属于异名磁极，因此相互吸引。

  2. 2. 下列哪种材料能被磁铁吸引？

    1. A聚乙烯
    2. B304不锈钢
    3. C陶瓷
    4. D钕铁硼
    答案：钕铁硼
    解析：钕铁硼 属于铁磁性材料（稀土永磁材料，磁性强，常用于扬声器。），能被磁铁吸引；聚乙烯、304不锈钢、陶瓷 都不是铁磁性材料。

  3. 3. 下列哪种磁铁常用于扬声器、传感器和磁吸固定？

    1. A磁针
    2. B电磁铁
    3. C蹄形磁铁
    4. D环形磁铁
    答案：环形磁铁
    解析：环形磁铁 的特点是：圆环状，一面是 N 极、另一面是 S 极。

  4. 4. 把 N 极与 N 极靠近，会发生什么？

    1. A吸引
    2. B没有相互作用
    3. C先吸引后排斥
    4. D排斥
    答案：排斥
    解析：同名磁极相互排斥，异名磁极相互吸引；N 极与 N 极属于同名磁极，因此相互排斥。

  5. 5. 下列哪种材料能被磁铁吸引？

    1. A铅
    2. B聚乙烯
    3. C镍
    4. D酒精
    答案：镍
    解析：镍 属于铁磁性材料（铁磁性金属，常用于不锈钢与合金。），能被磁铁吸引；酒精、聚乙烯、铅 都不是铁磁性材料。

  6. 6. 下列哪种磁铁常用于制作指南针，判断地理方向？

    1. A条形磁铁
    2. B圆片磁铁
    3. C磁针
    4. D电磁铁
    答案：磁针
    解析：磁针 的特点是：细小的针形磁体，能绕支点自由转动。

  7. 7. 把 S 极与 S 极靠近，会发生什么？

    1. A先吸引后排斥
    2. B没有相互作用
    3. C吸引
    4. D排斥
    答案：排斥
    解析：同名磁极相互排斥，异名磁极相互吸引；S 极与 S 极属于同名磁极，因此相互排斥。

  8. 8. 下列哪种材料能被磁铁吸引？

    1. A橡胶
    2. B空气
    3. C铸铁
    4. D银
    答案：铸铁
    解析：铸铁 属于铁磁性材料（含碳量高的铁合金，具有铁磁性。），能被磁铁吸引；银、空气、橡胶 都不是铁磁性材料。

  9. 9. 下列哪种磁铁常用于冰箱贴、包装磁扣和手工制作？

    1. A环形磁铁
    2. B条形磁铁
    3. C圆片磁铁
    4. D蹄形磁铁
    答案：圆片磁铁
    解析：圆片磁铁 的特点是：扁圆片状，体积小、磁力集中。

  10. 10. 把 N 极与 S 极靠近，会发生什么？

    1. A先吸引后排斥
    2. B没有相互作用
    3. C排斥
    4. D吸引
    答案：吸引
    解析：同名磁极相互排斥，异名磁极相互吸引；N 极与 S 极属于异名磁极，因此相互吸引。
